# AI Assistance Disclosure

I used Claude selectively during the development of this project as a
supporting tool rather than as the primary author of the system.

The main system architecture, service design, data flow, recommendation
approach, streaming and batch processing, database design, and other
core technical decisions were developed and reviewed by me.

I used Claude for a limited amount of routine and repetitive work,
including:

- reorganizing, shortening, and clarifying parts of the README and
  technical documentation
- drafting some repetitive unit-test structure and suggesting
  additional edge cases
- helping with a few straightforward MapReduce test cases
- helping with limited request/response schema and validation
  boilerplate
- assisting with small utility functions and other routine code where
  the implementation was repetitive
- helping with limited CRUD or similar boilerplate
- assisting with small Docker and configuration snippets
- reviewing selected existing code for possible edge cases, cleanup
  opportunities, and simple optimizations
- suggesting minor refactoring opportunities where the behavior of the
  code did not need to change

For coding-related suggestions, I reviewed and adapted the output to
fit the project's existing structure, interfaces, and requirements.
I made the final decisions about what to include and how the system
should work.

The use of Claude was limited to supporting parts of the project and
did not replace my work on the main architecture, system design, core
algorithms, or technical decisions.

The original AI conversations were not preserved when the project was
developed. This document is therefore a retrospective summary of my AI
use and is not a complete transcript of those interactions.

I remain responsible for the final code, tests, documentation, design
decisions, and reported results in this repository.
