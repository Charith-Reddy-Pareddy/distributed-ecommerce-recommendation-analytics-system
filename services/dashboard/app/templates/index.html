Distributed E-Commerce Recommendation Analytics System

Live view over the serving layer: Elasticsearch search, Cassandra demand data (fed by Spark Structured Streaming), and HBase-served ALS recommendations.

Product Search Elasticsearch

300 real Amazon products (titles, brands, prices, ratings, images, ASINs) sourced from the public McAuley-Lab/Amazon-Reviews-2023 dataset.

Top Products Postgres / SQL

Views, cart-adds, and purchases per product, aggregated live from analytics-service's SQL tables.

Event Volume by Day Postgres / SQL

Daily event counts by type, computed with a SQL GROUP BY over the same events feeding recommendations and demand tracking.

Autonomous Tuning Serving-Layer Optimizer

An independent service that watches real Postgres query patterns, real per-product Cassandra demand volume, and real Elasticsearch indexing load, and actually acts on what it observes -- creating/dropping Postgres indexes, classifying products hot/cold for Cassandra, and adjusting Elasticsearch's refresh_interval.
