# Distributed E-Commerce Recommendation Analytics System

A distributed e-commerce project for product discovery, recommendation, and event analytics.

## Datasets

### Amazon Reviews 2023

- [McAuley Lab dataset site](https://amazon-reviews-2023.github.io/)
- [Hugging Face dataset](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023)

The dataset includes product reviews, ratings, timestamps, and product metadata. It is used for the product catalog and review-based recommendation work.

### RetailRocket e-commerce dataset

- [Kaggle dataset page](https://www.kaggle.com/datasets/retailrocket/ecommerce-dataset)

This dataset contains real-world views, add-to-cart and transaction events, item properties, and a category tree. It is used for event processing and clickstream recommendation work.

Dataset files are downloaded from their source pages and kept outside this repository. The two datasets have separate product identifiers.
